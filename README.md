# Banking Membership API

A backend REST API for managing banking customers and membership subscriptions.

## Project Goals

- Create and manage customers
- Retrieve available membership plans
- Create, upgrade, and cancel subscriptions
- Enforce subscription business rules
- Store data in PostgreSQL
- Implement automated tests

## Tech Stack

- Python
- FastAPI
- PostgreSQL
- SQLAlchemy
- Alembic
- pytest
- Docker
